# SKILL 03｜AI 協作網頁工具包

適用：女力 AI 協作程式設計與網頁工具實作班（NT$20,000）。目標：以 AI 協作建立「工作進度管理」展示網頁，能操作、能測試、能說明限制。

## 工具包清單
- 一頁式 PRD：請使用 [PRD-作品規劃手冊](../../PRD-作品規劃手冊.md)。
- 介面欄位表：任務名稱、負責人、期限、狀態、說明。
- 測試清單：新增、編輯、刪除、搜尋、篩選、CSV 匯出。
- 作品交付：作品網址、原始碼、操作說明、測試紀錄。
- 命名規範：品牌顯示名、社群顯示名、作品標題及網站代稱要一致。

## 入門網域與系統架構
~~~text
使用者瀏覽器
   │ HTTPS
   ▼
Cloudflare Pages 預設網址（亦可之後設定自有網域）
   │
   └─ HTML + CSS + JavaScript
         ├─ 任務列表
         ├─ 新增／修改／刪除
         ├─ 搜尋／篩選／CSV
         └─ 練習儲存：localStorage（僅該瀏覽器）
~~~

**注意**：localStorage 不是多人協作資料庫，不能拿來存敏感客戶資料。Cloudflare Pages 免費額度、網域與資料庫使用條件依官方當時規範而定，課程不保證永久免費。

## AI 協作開發指令

你是我的網頁開發協作員，請依我提供的 PRD 產出最簡單的 HTML／CSS／JavaScript 工作進度管理工具。第一步只列功能與資料欄位，不直接寫大量程式。每次完成一項功能後，提供：
1. 要修改哪些檔案；
2. 程式碼與安全風險；
3. 我可以親手執行的測試；
4. 若測試失敗如何回復。
嚴禁聲稱「已測試成功」，除非我回報實測結果。
