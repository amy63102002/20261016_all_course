## 統一識別規格
- 對外課程系列名稱：**女力 AI 數位職涯培育**
- 講師：**阿茲老師｜AI 自動化工程師・AI 工作流程設計師**
- 專業團隊背景：**造雨人科技股份有限公司**（實際主辦與合作角色以招生公告為準）
- 學員作品：可使用個人／品牌名稱；網站、LINE OA、社群顯示名稱應一致。

## 實作倫理
練習資料務必使用測試或匿名內容。AI 結果需要人工檢查；PRD 中需寫清楚儲存位置、權限、平台費用與系統限制。
