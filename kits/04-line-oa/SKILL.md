# SKILL 04｜LINE OA × AI 接待流程包

適用：女力 LINE OA × AI 工作流進階班（NT$20,000）。目標：把 LINE 訊息、客戶表單、追蹤表做成可演示的接待與人工處理流程。

## 工具包內容
1. 社群與 LINE OA 命名一致表：對外品牌／LINE 名稱／網站名稱／社群名稱。
2. LINE OA 圖文選單草稿：服務介紹、預約諮詢、常見問題、聯絡資訊。
3. FAQ 工作卡：客戶問句、標準答案、應轉人工的情況。
4. Google Forms 欄位設計：需求類型、偏好時段、授權聲明（僅課堂示例）。
5. Google Sheets 追蹤：表單編號、需求摘要、狀態、負責人、更新時間。
6. AI 工作流檢查單：以講師**預建環境與範本**示範觸發、摘要、分類及人工核對。

## 教學系統流程／架構圖
~~~text
客戶
~~~

此示意**不表示課堂直接製作正式版 LINE Messaging API Bot**。若要實際串接真實客戶個資、Webhook 或自動推播，須另行評估 LINE 與 Google 的政策、資料權限及費用。

## AI 客服話術提示詞

你是 LINE OA 客服文案協作員。依我提供的服務資料，整理十組常見問答，每組包含「客戶原話、簡短回答、需人工確認條件」。對價格、日期、資格、退款、醫療或法律議題，資料不足時一律標示待確認，不自行承諾。回覆語氣清楚、自然，不催促成交。

## 工作流驗收
- [ ] 圖文選單按鈕連結有實際測試。
- [ ] 品牌、LINE OA、社群名稱一致。
- [ ] 表單有完整欄位、必要使用告知與測試資料。
- [ ] Sheets 能對應表單欄位與處理狀態。
- [ ] AI 摘要及分類結果經人工確認。
- [ ] 畫出錯誤與人工接管流程。
- [ ] 交付畫面截圖／測試紀錄／操作流程說明。

可探索：LINE OA 營運助理、數位客服、CRM 作業助理。不保證取得 LINE 認證，也不宣稱具備正式客服系統商用穩定性。
