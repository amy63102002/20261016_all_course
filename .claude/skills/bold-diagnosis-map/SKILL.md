# Bold Diagnosis Map 頁面風格

把多個方案（課程、服務、產品）做成一張可互動的「對症地圖」。讀者先點自己的狀況，地圖連線亮出對應方案，再一路往下看流程與詳細卡片。

## 一、視覺語言

**整體感覺**：像貼在白板上的貼紙卡片。扁平、高對比、好玩但資訊清楚。沒有漸層按鈕、沒有柔和模糊陰影。

**設計 token（放在 `:root`）**

```css
--ink: #141414;      /* 所有框線、硬陰影、主按鈕 */
--paper: #FFFDF7;    /* 卡片底 */
--yellow: #FFD43B;   /* 提示橫幅、重點標籤、螢光筆 */
--pink: #F7AFC6;     /* 被選中的方案、列點圓點 */
--blue: #93CBEA;
--green: #5BB592;    /* 卡片牆整區背景 */
--mint: #CFEBDD;
--orange: #FF6B3D;   /* 強調色：選中外圈、hover 陰影、箭頭 */
--cream: #FFF4D6;    /* 「今天就做這一件事」虛線框底 */
--line: 3px solid var(--ink);
```

**必備規則**
- 框線：卡片、按鈕、膠囊一律 2.5–3px 純黑實線。
- 陰影：只用硬陰影 `box-shadow: 8px 8px 0 var(--ink)`（小元件 4px）。不要 blur。
- 圓角：大卡 22–26px，膠囊 999px。
- 背景：頁面用天空藍漸層加幾團白色橢圓雲；面板內用點狀格線 `radial-gradient(#D9D4C7 1.4px, transparent 1.4px) / 22px 22px`。
- 字體：英文大標用 `Lilita One`（Google Fonts），中文用 `Noto Sans TC` 700/900。每區塊有「小字 kicker（如 `01 · DIAGNOSE`）＋巨大英文標題＋一行中文副標」。
- 重點字：黃色螢光筆底線 `linear-gradient(transparent 55%, var(--yellow) 55%)`。
- hover：元件往左上移 2px，並出現橘色硬陰影。

## 二、頁面流程（依序）

1. **固定頂欄**：膠囊形白條加黑框和硬陰影。左邊品牌名用黃底小方塊框住關鍵字，右邊是錨點導覽。手機版改為不固定。
2. **Hero**：點狀格線大面板，黃色膠囊標籤，一行橘色英文副標，中文大標用 900 粗體，兩顆按鈕（黑底主按鈕、白底次按鈕），下面放 2–3 個不同底色的數字方塊。
3. **01 Diagnose 互動診斷地圖**（核心）
   - 左側大面板：最上方黃色膠囊橫幅寫操作提示；接著是「狀況」列（10–12 個灰框膠囊）、一條虛線分隔、「方案」列（每個方案一顆膠囊，含編號圓點和英文小字），最底下是黑色膠囊寫最終目標。左側用圓形圖示標示列名。
   - 點一個狀況：膠囊變黑底白字並加橘色外圈；對應方案變粉底加黑框和硬陰影，其餘方案變淡；用 SVG 三次貝茲曲線從狀況畫線到每個對應方案（黑色 3px，用 dash 動畫畫出來）；橫幅改成「『X』往下連到的方案都亮起來了。再點一次就收起來。」
   - 右側 sticky 說明卡：`SYMPTOM` kicker、狀況標題、粉色標籤、2–3 句說明、一個虛線框「今天就做這一件事」（黃色小膠囊標題），以及每個對應方案一顆「翻到 X 卡片 →」黑色按鈕。
4. **02 The Map 流程地圖**：4 欄階段卡（01 → 04），每張卡的標頭用不同底色，左邊放圓形編號，卡片之間放橘色箭頭；卡內是可點擊的迷你方案框。最下方用虛線框寫一句提醒。
5. **03 Cards 卡片牆**：整區綠色滿版背景，上下各一條黑線。上方是篩選膠囊（全部／各階段，選中變黑底）。每張卡：彩色標頭（階段膠囊、英文大字、中文全名）＋白色內文（價格大字、時數、一段定位、帶粉色圓點的成果列表、可選的數字強調框、橘色「注意」提醒框、可展開的課綱 `<details>`）。
6. **Q&A**：每題是一張黑框硬陰影卡，左邊黃色圓形「Q」，用 `<details>` 展開收合。
7. **重要說明**：奶油色底、黑色虛線框。
8. **頁尾**：黑底白字。

## 三、互動實作要點

- 狀況資料寫成 JS 陣列：`{ t: 標題, to: [方案id...], tag, d: 說明, todo: 今天就做的事 }`。方案膠囊和卡片用靜態 HTML（SEO 友善），狀況膠囊由 JS 產生。
- 連線：用 `getBoundingClientRect()` 算出狀況底部中點到方案頂部中點，畫 `M x1,y1 C x1,y1+dy x2,y2-dy x2,y2`；在 `resize` 時重畫。SVG 設 `pointer-events:none` 並放在膠囊後面（z-index）。
- 任何連到卡片的錨點：如果卡片被篩選隱藏，先切回「全部」，再讓卡片閃一次橘色外框。
- 狀況按鈕用 `<button aria-pressed>`，橫幅和說明卡加上 `aria-live="polite"`。
- `prefers-reduced-motion`：關掉連線動畫和平滑捲動。
- 手機版（≤640px）：列名改為行內顯示，所有網格變單欄，說明卡排到地圖下方，不能出現水平捲動。

## 四、內容原則

- 原始資料（價格、時數、課綱、限制聲明）逐字保留，不新增日期、地點、名額或保證。
- 狀況要用讀者自己的話寫（「不會寫程式，怕跟不上」），不要用行銷口號。
- 「今天就做這一件事」要是 5 分鐘內做得到的具體小行動。
- 有免責聲明的方案，在卡片內用橘色「注意」框明確寫出。
