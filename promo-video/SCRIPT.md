# 介紹影片腳本：三個入口，找到你的起點

- 規格：1920×1080、30fps、約 75 秒、無旁白（字卡帶敘事），之後可另出 9:16 直式版
- 風格：沿用網站的天空藍漸層、米白卡片、3px 黑框、硬陰影、Lilita One＋Noto Sans TC
- 用字：一律「你」（跟 LINE OA、遊戲頁一致）；課名用短名（A 一日班…），不用「女力」
- 畫面來源：S3–S5 是用 Playwright 開 Chrome 實際操作網站錄下來的畫面，放進「瀏覽器視窗」外框裡，再加慢速推近（Ken Burns）和字卡
