# 10/19 何惠雯 × 阿茲｜VIP 輔導會議紀錄

- 參與者：何惠雯、阿茲、Nirava 如珺
- 下次會議：2026-10-27（二）上午

## 核心結論

先完成課程銷售頁調整與新版 PRD 產品手冊，再進入社群選題與招生推廣。課程主軸聚焦「協助 AI 新手重返職場、轉職，或提升現有工作能力」，招生頁移除政府補助相關內容。

## 現況與卡點

- 銷售頁視覺已獲肯定，接下來補強品牌識別、講師介紹、學習成果與報名入口。
- 頁面偏向介紹「教什麼」，沒有清楚呈現「學完能做什麼、能帶走什麼」。一般人看課綱只知道內容很豐富，看不出自己能拿到什麼。
- 新版課程方案尚未整理成團隊共用的 PRD，影響文案與社群選題的一致性。PRD 是內部依據，對外網頁要跟它一致；不一致時先改 PRD。
- 過去招生以熟人及補助需求者為主，曾有學員為用滿補助而選擇超出自身程度的課程。接下來要拓展符合定位的陌生客群。

## 已確認方向

1. **銷售頁補足品牌與成果說明**
   - 確定講師／品牌名稱，並與社群帳號名稱統一（曾有學員沒統一造成困擾）。
   - 補上講師經歷、專長與實務經驗（例：20 年工程師資歷，擅長把客戶零散的想法變成能落地的網站或方案）。
   - 每個方案列出具體成果：完成的作品、可帶走的工具包或模板；實際交付內容由阿茲確認。
   - 痛點寫得更具體：例如上班怎麼用 AI、怎麼用 AI 操作辦公軟體、怎麼做智能客服；轉職時怎麼展示作品集。
   - 「想做展示作品」與「面試不知道如何介紹自己」合併，避免被誤認為主打面試技巧。
2. **政府補助內容移除**：會中討論過另開頁面或加補助 FAQ，最後確認先從招生頁移除，以課程本身的學習價值吸引學員。
3. **報名以 LINE 文字客服為主要諮詢入口**
   - 先用文字協助判斷適合的課程；文字訊息也留有紀錄。
   - 有明確報名意願、但仍有個別問題時，再安排通話。一對一通話成交適合 29,800 以上的高單價方案。
   - 不必要求每位報名者先一對一諮詢；方案超過兩種，不適合一對多說明會，線上說明會非必要步驟。
   - 報名按鈕要多放，頁面中段也能報名；手機滑動途中可彈出一兩次報名視窗。
4. **產品與頁面完成後，再規劃社群內容**
   - 圍繞受眾真實困擾（例：離開職場幾年回來，發現職場都在用 AI），搭配 AI 實作示範、實用知識與講師故事。
   - FB／IG 為主要經營方向；Threads 先用來測試話題，再把反應好的寫成 FB／IG 長文。
   - 社群助教需要新版 PRD 產品手冊才能規劃選題。
